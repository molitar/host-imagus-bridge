# Host Imagus Bridge 3.0.3

**3.0.3 — image links that Imagus does not recognise work again.** Plain text links to an image host (opaque address, no picture in the link) are now resolved by HIB when you hover or right-click them, if Imagus shows nothing. HIB only rewrites the link after the browser has verified a real picture, never to a video or advert clip. The spinner now stops when the picture is ready. Download directories, navigation links and links to other kinds of pages are left alone. No new permissions.
