# Host Imagus Bridge 3.0.0

**3.0.0 — a new HIB.** Adds HIB's own video player (MP4 / HLS / DASH, resume, keyboard control) with styled ASS subtitles plus SRT/VTT, hover-to-scan and right-click-to-play, a Tools page (Manage Sites, Save / Restore settings as bookmarks, Report Issue, Submit Request) and two optional Beta features, Capture streams and HEVC support, both off by default. HIB still works only on the sites you add and sends nothing to any server of its own. Firefox may ask you to approve the new permissions (bookmarks, downloads, webNavigation, cookies) when you update.
